# SYNC-20261115-386 – Import alter WIFI/BOTH-Profile aus einer alten App-Version in das neueste Release pruefen (aus -378)
- Erstellt am: 2026-11-15
- Absender: Architecture
- Empfänger: QA & Testing
- Priorität: MEDIUM
- Status: COMPLETED
- Übergabegrund: Benutzerentscheid 2026-11-15 zu SYNC-20261115-378: Diesen Punkt fuehrt QA selbst aus statt des Inhabers (Punkt 3 der Anleitung in -380 entfaellt fuer den Inhaber).
- Aufgabenbeschreibung: 1. Im Emulator eine alte Version aus `releases\` installieren, die Profile mit Netzmodus WIFI bzw. BOTH (vor der Umstellung auf PC-Kennung) kennt; passende Version selbst bestimmen und im Bericht nennen. Benutzerfreigabe: Fuer diesen Auftrag duerfen auch Release-APKs aus `releases\` (alte App com.sync2pc.app bzw. alte LeoSync-Versionen) im Emulator installiert werden.
  2. Darin je ein Profil mit WIFI und mit BOTH anlegen (Testordner und SMB-Testfreigabe nach QA-Prompt §3), mindestens einen Lauf ausfuehren, dann eine Sicherung exportieren.
  3. Neuestes Release (`releases\LeoSync-0.19.9.apk` bzw. die zum Zeitpunkt neueste Version) installieren, Sicherung importieren.
  4. Pruefen: Umwandlung auf PC-Kennung wie im Import angezeigt; kein Profil verloren; Passwoerter bzw. Hinweis auf erneute Eingabe korrekt; erster Lauf ohne Fehlloeschung auf Handy und PC; Verhalten im bekannten und im unbekannten Netz plausibel.
  5. Danach alle selbst angelegten Profile entfernen, alte App deinstallieren und den Ursprungszustand per Import wiederherstellen (CLAUDE.md 1, Emulator).
- Technischer Kontext: Release-Pruefung -347 hat den Umzug alt nach neu bestanden (4 Profile, 603 Staende), aber nicht gezielt WIFI/BOTH mit Umwandlung. Testanleitung fuer den Inhaber in -380 (Abschnitt «Testanleitung für den Inhaber», Punkt Import) kann als Vorlage dienen.
