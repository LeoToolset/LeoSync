# LeoSync – Help

LeoSync backs up photos, videos and any folder from your phone to your Windows PC – directly on your home network, without a cloud and without an account. Files only travel between phone and PC.

## 1. On the PC: share a folder

1. In Explorer, right-click the target folder (e.g. `D:\Photos`) → **Properties** → **Sharing** → **Advanced Sharing**.
2. Tick **Share this folder** and give it a share name (e.g. `Photos`).
3. Under **Permissions**, allow **Change** and **Read** for your Windows user.
4. Find the PC's IP address with `ipconfig` in the command prompt (e.g. `192.168.1.20`). Ideally, give the PC a fixed address in your router.

### Create a dedicated local user for LeoSync

**Recommendation:** Never use an administrator account for LeoSync; use a dedicated user with restricted rights and a strong password (on the PC as well as on the NAS). If the credentials ever fall into the wrong hands, for example through a fake server on the network, the damage is limited to the one shared folder.

Instead of your normal Windows account, you can use a dedicated local user just for LeoSync. That way, your personal password (or your Microsoft account password) is not stored in the app, and the user only gets rights to the one shared folder.

- **Create the user:** Settings → Accounts → Other users (Windows 10: Family & other users) → Add account → **I don't have this person's sign-in information** → **Add a user without a Microsoft account**. Choose a user name (e.g. `leosync`) and a password. The password must not be empty, because Windows refuses network access with an empty password.
- Alternatively, open the command prompt as administrator and run `net user leosync * /add`. Windows then asks for the password.
- **Share permission:** In Explorer, right-click the target folder → Properties → Sharing → Advanced Sharing → Permissions → **Add**. Enter the user name, click **Check Names** and confirm with **OK**. Then allow **Change** and **Read**.
- **Folder permission:** In the same Properties window, go to **Security** → **Edit** → **Add**, enter the user and allow **Modify**. Windows checks both share and folder permissions, and the stricter setting applies.
- **Enter it in LeoSync:** In the profile, enter the new user name and its password. For a local account, you usually leave the domain field empty. If the sign-in does not work, try `PC-NAME\leosync` as the user. You find the PC name under Settings → System → About. Use **Test connection** to check the result.

## 2. In LeoSync: create a profile

Tap **Add profile** and choose the type:

- **Back up photos & videos** – from the camera to the PC, sorted automatically by year, month and travel country (e.g. `2026\06 - Egypt`). Optionally remove them from the phone afterwards.
- **Sync a folder** – any folder 1:1, in one or both directions.

The wizard guides you step by step through name, source, target and options. For the target, the PC is enough (`\\192.168.1.20`) plus user and password; **Choose folder on the PC…** then lists the shares and folders. **Test connection** shows right away whether everything is correct.

For photo profiles you choose the **folder structure**: `Year\Month - Country` (default), `Year\Country\Month` or `Year\Month\Country`. It can be changed until the profile's first sync. Several photo profiles with the same target must use the same structure.

**Country folders** (photo profiles only): For these LeoSync reads the capture location (GPS data in the photo) from your photos to choose the folder. Only when you choose country folders does LeoSync ask for the **Location in photos** permission, with an explanation. The location is evaluated only on the phone and neither stored nor sent; the photos themselves are transferred unchanged. If you decline, country folders stay off; if the permission is missing later, the profile says "Capture location: permission missing" with **Grant**.

Under **PC ID** in the profile you see whether LeoSync recognises your PC: **PC recognised**, **Not recognised yet** or **Different PC**. LeoSync recognises your PC by its ID, so it only syncs with your PC and not with another device. The ID is checked before the user name and password are sent. If the PC is not recognised yet, tap **Test connection** when you are at home. With **Different PC** (e.g. after a fresh Windows installation, when the ID changes) nothing is synced; check that it really is your PC answering, then confirm with **Test connection**. LeoSync needs no Wi-Fi name and no location permission for this.

Under **Known networks: N** you see in how many networks LeoSync has already reliably recognised your PC. On unknown Wi-Fi networks it only searches briefly for the PC to save battery; the PC ID is what protects you, not the known networks. LeoSync does not show network names, only the number. After a move or a router change you can reset the known networks with **Forget**: LeoSync learns them again the next time it connects, and no file is lost. Profiles from an old backup that used to depend on the Wi-Fi name are switched to the PC ID on import (a history entry says so); if a profile does not know the PC yet, tap **Test connection** once.

Number fields in a profile only accept values in the allowed range: **Empty trash after … days** 0 to 3650 (0 = never), **Safety brake** 1 to 100 %. An invalid value is reported below the field and **Save** is blocked. In the wizard, **Next** does not let you leave a step with an empty or invalid number field; **Save** jumps to the first step with an error. For **filters**, a pattern with an unclosed bracket is rejected. The filter card shows a short summary, and the profile card says **Filter active**.

When saving, LeoSync warns if profiles overlap, also between a photo profile and a folder profile: when the photo profile's target folder is the same as, lies inside, or contains the folder profile's PC folder, and when a photo source folder and the phone folder lie inside each other while the folder profile writes files to the phone. Photo profiles capture the same folder path on all storage volumes (internal storage and SD card), so the warning compares phone folders regardless of the volume. A folder profile directly at the top level of the storage also warns, because it contains all photo folders. Continue with **Save anyway**.

### Turning on encryption

On the **Encryption** card in the profile (collapsed by default) you decide per profile whether the transfer to the PC is encrypted, so that nobody on the network can read along. The profile card shows a shield-with-lock icon at the top right when the profile's last sign-in was actually encrypted (not just because the setting is "If possible"). After changing the setting, the share or the subfolder, the card shows no icon until the next connection:

- **Off:** no encryption. Only recommended on a network you trust.
- **If possible (recommended):** encrypted as soon as the PC supports it. Otherwise the connection stays unencrypted. This is the default, also for existing profiles.
- **Required:** connects only if encrypted. If the PC cannot do that, no connection is made and no password is sent. Most secure.

**Test connection** shows whether the connection is encrypted and which SMB version is used. Encryption exists only from SMB 3; Windows 10 and 11 support it, on a NAS (Samba) it depends on the device's settings. If **Required** is selected and the PC cannot encrypt, a message says so. For automatic syncs LeoSync reports this only once per profile until a sync succeeds again; when you start a sync by hand, the message appears every time.

**Steps on the PC or NAS** (per the manufacturer's documentation; not checked by us on every device). **Test connection** in LeoSync always shows whether it worked.

- **Windows 10 and 11:** Open PowerShell **as administrator**. Encrypt one share: `Set-SmbShare -Name <share name> -EncryptData $true`. All shares of the PC: `Set-SmbServerConfiguration -EncryptData $true`. Check the state: `Get-SmbShare -Name <share name> | Select-Object Name, EncryptData` (`True` = on). Afterwards the share accepts only devices with SMB 3 and encryption; others get «Access denied». Do not set `RejectUnencryptedAccess` to `$false`; Microsoft advises against it.
- **Samba (e.g. Linux, many NAS):** In `smb.conf`, set the parameter `server smb encrypt` (globally or per share) to `desired` or `required`. This exists only from SMB 3, and `server max protocol` must allow SMB3 or newer.
- **Synology and QNAP:** Menus differ between firmware versions; please use the manufacturer's help. On Synology (DSM 7) the option is called «Transport encryption mode on SMB3» (Control Panel › File Services › SMB › Advanced Settings). On QNAP the highest SMB version must be set to SMB 3.0.
- **The server only supports SMB 2:** Then encryption is not possible, and LeoSync does not connect with **Required**. Turn on SMB 3 on the server (or update it). If that is not possible, choose **If possible** or **Off** in LeoSync. The transfer is then unencrypted and should only happen on a trusted home network.

New profiles only start after you tap **Sync** once. You can **simulate** first what would happen.

## 3. Day to day

- **Automatic:** As soon as the phone is connected to a Wi-Fi where LeoSync recognises your PC, it syncs in the background. Known networks (see section 2) it checks as before; on an unknown Wi-Fi it only searches briefly for the PC to save battery.
- **Updates:** LeoSync is updated through Google Play; there is no update page in the app. **About LeoSync** says "Updates are delivered through Google Play".
- **After the import:** When you import a backup, the profiles deliberately wait for their first start. At the top of the home screen the **After the import** card shows the next step per profile with a button: **Choose folder** (if the phone folder has to be linked again), **Test connection** (if the PC is not recognised yet) and **Start now** (first sync). The card can be collapsed but not swiped away; it disappears as soon as every profile has run once.
- **Check interval for folder profiles:** Under **Settings → Transfer**, **Folder profiles: check interval (minutes)** (15 to 1440, default 60) sets how often LeoSync checks folder profiles for changes. The setting applies to all folder profiles (formerly per profile, the shortest one was effective); on update the app takes over the shortest previous interval. Checks only run while an active folder profile exists.
- **New photos (minimum age):** **Minimum age for photos (minutes)** under **Settings → Transfer** sets how old a photo must be at least. After a series of photos only one catch-up run happens, as soon as the newest photo has reached the minimum age (instead of one per photo); if no photos are ready to transfer, no run starts and no history entry is created.
- **Mobile data/VPN:** Under **Settings → Transfer** you can allow automatic sync outside Wi-Fi as well (off by default). This can use data and, with some mobile plans, cost money, for example abroad. If the PC is not reachable, LeoSync only retries every 2 hours outside Wi-Fi. When roaming (outside your home mobile network, e.g. abroad), no automatic run starts over mobile data or VPN; Wi-Fi and starting by hand work as usual.
- **Only while charging:** If you wish, LeoSync only syncs while the phone is charging (Settings).
- **Manual:** Tap **Sync** or pull down at the very top of the home screen. If a sync is already running, your start is not discarded but run once afterwards: LeoSync says "Will start after the current sync.", and the status card shows "Next: all profiles" (for an automatic start "Another sync follows."). **Pause** or cancelling discards the queued start.
- **Pause:** The pause icon at the top right – for a while or "forever" (manual only). The resume icon (triangle) in the same place resumes. The status card then shows the heading "Paused" (with a pause icon) and below it "Paused until 06:23" or "Paused – manual syncing only".
- **Icons on the profile card:** At the top right the card shows only the icons that apply, from left to right without gaps: **PC** (the PC's identifier is known, "PC recognised") and the **shield** (the last sign-in was encrypted; red with a warning triangle if encryption was refused). The state is also shown in the text lines below the name. There is no Wi-Fi icon any more because LeoSync no longer reads the Wi-Fi name.
- **The dog** shows the state: sleeping = everything backed up, running = sync in progress, standing = waiting for your decision, sitting = waiting (e.g. for Wi-Fi, the first sync, or files that follow later). The status card never says "all up to date" with an open conflict, no connection, pending files, or an error in the last run.
- **"Not everything backed up yet"** (with a repeat icon): If a file changed on the phone or PC during the sync, LeoSync skips it in that run and catches up later. The run still counts as successful; the history says "· N follow later", and the home page says "N files changed during the run and follow at the next sync." You do not need to do anything: LeoSync automatically starts a follow-up run after 5 minutes, at most one per hour (pause and "manual only" are respected). After that the usual triggers such as folder check and Wi-Fi apply. As soon as a run ends without pending files, the card says "All backed up and up to date" again.
- **"No connection" and "Start not possible":** If a start could not be carried out because the PC or Wi-Fi is not available, the status card shows "No connection" (the sitting dog on a blue circle while files are waiting) instead of "Ready" or an error; a manual start reports "Start not possible". "All backed up" appears only once every active profile has been started successfully by hand. "Waiting for the home Wi-Fi." appears only after an interruption in the middle of a run. With "No connection" the card also shows how many files are waiting (1 file / N files waiting for synchronisation). The profile card of a folder profile additionally shows "· N open": new files or files changed since the last comparison in the phone folder. The number is counted on the phone only (no network); there is no counter for "PC → Phone", and Photos profiles do not show it.
- **Backup:** The messages on export and import also count the sync state of folder profiles (previously only photo files; the folder state was already included).
- **Date and time:** All displays follow the phone's system settings (region, 12 h/24 h), even if the app language differs (e.g. US format with a German app). Fixed formats remain for file names, backup/export, diagnostics and trash day folders.
- **"Last synchronisation":** The home screen shows the last run without errors (with the profile), not the last attempt; a run without errors counts even if there was nothing to transfer. Runs with errors, partial success or cancellation do not change the time. Without a successful run it says "No successful synchronisation yet." (wording not checked against the app).
- **"Next check at 10:21":** This line under the status on the home screen tells you when LeoSync will look again by itself if a check is scheduled for later, for example the follow-up sync for photos just taken, or a new attempt when the PC was not reachable. It only appears if at least one profile exists, nothing is running or waiting, and you have not paused manually.
- **"Messages" on the home screen:** Problems are collected in one card you can page through (arrows and counter), grouped by cause: if the same cause affects several profiles (the same PC, share or account), it appears once, with the affected profiles. Each profile keeps its own state; no error disappears through grouping. The colour follows the most serious entry (reddish: safety brake, security, you need to act; yellow: decisions and temporary messages). Tips (for example battery) and the checklist after the import are there too, uncoloured. "Try again" repeats only the profiles of the group; you enter a new password once per PC and account. "PC not reachable" appears only after 24 hours without a successful run. The heading of the status card is **Errors** (safety brake, security, you need to act, missing required permission), **Waiting for you** (conflict, month folder, delete confirmation) or **Messages** (temporary).
- **Profile names:** Each profile name may occur only once (case and spaces at the edges are ignored). It is checked at **Next** in the name step, when saving and when editing. Existing duplicate names are not renamed but reported when editing; saving other changes remains possible. Import with **Add** deliberately does not check names.
- **"Access denied" in the connection test:** If encryption is set to **Off**, the message names it as a possible cause (the server may require it).
- **Import "Replace":** The warning stays fixed at the top in the error colour; the backup details scroll below it.
- **"Phone folder: access lost":** If LeoSync no longer has access to a profile's phone folder (e.g. after importing the settings), the profile card shows (with a warning icon) "Phone folder: access lost – tap and choose again". Tapping opens the profile, where you choose the folder again.
- **Free up space:** In the tools on the home screen, LeoSync removes old files from the phone that are verifiably on the PC. Each file is checked on the PC first; you choose by age, folder, file type and size and see a preview. Photos and videos go to the gallery trash (Android 10 has none; a note says so). The result states how many files were deleted and skipped and how much space was freed. **Tip:** Free up phone storage only after a sync, most safely with **Free up space** in LeoSync. Google Photos can delete originals before they are backed up (**Free up space** in Google Photos); LeoSync shows a one-time note about this after the photo-profile wizard.
- **Backup of your settings:** Profiles, settings and sync state can be exported to a file and imported again. Passwords are only included, encrypted, with an export password. The app language is not part of the backup. On import, **Replace** is highlighted in a warning colour because it replaces the existing profiles.
- **History:** With **Delete history** you remove the entries. LeoSync asks first and then offers **Undo** while the message at the bottom is visible. Error entries show a recommended action. The history filter resets when you leave the page.
- **Language:** The app language follows the phone's language (German, otherwise English). Under Settings → Language you can set it permanently.

## 4. Keeping your files safe

- **Check after upload:** LeoSync reads the file back from the PC and compares it with the original. The levels range from *Off* to *Complete*; the default is *Medium*. If photos are removed from the phone, a check is always done.
- **Trash:** For folder profiles, deleted and overwritten files go to the `@LeoSync-Bin` folder (on phone and PC/NAS; a normal, visible folder, whereas the former name `.LeoSync-Bin` was hidden on QNAP/Samba). LeoSync renames older trash folders (`.LeoSync-Bin` and others) automatically on the next run or moves their contents, without copying or overwriting anything; the history shows a line about it. If a PC rejects the name `@LeoSync-Bin`, LeoSync uses `.LeoSync-Bin` there and warns in the history. The row for each version in the trash shows "changed …" (the file's modification time), otherwise "deleted on …". Entries can be restored via **Tools → Trash**: choose the profile, select entries and tap **Restore** (or **Delete permanently**). Each file on the phone has **Open**: it opens the file for viewing only with the default app or the Android app chooser, nothing changes in the trash; without a suitable app or if the file is missing, a message appears. Files only on the PC have no **Open**. **Show** (Phone and PC / Phone only / PC only) and **Day** narrow the list; if a filter changes and the selection would contain hidden entries, the selection is cleared. The selection bar and the delete dialog name the sides concerned. **Restore** always writes back to phone and PC, even with a filter; the dialog states how many files are replaced according to the sync state (the current version goes to the trash first) and how many are newly created. On the phone, LeoSync places an empty `.nomedia` file in the trash so the gallery does not show it (not for download folders with a number tag); files in the trash are not backed up by a photo profile and not offered by **Free up space**. It is emptied after 30 days (adjustable). Photo profiles have no trash of their own: removed photos are in the gallery trash. A note appears in the trash while the move from `.LeoSync-Bin` to `@LeoSync-Bin` is waiting for pending restores (nothing is lost; if restores failed several times, try them again or discard them) or when your PC or NAS rejects the name `@LeoSync-Bin` and LeoSync stays with `.LeoSync-Bin` (normal, your files are protected).
- **Safety brake:** If many files would be deleted at once (default: more than 20 %) or a whole folder is missing, LeoSync stops and asks you first. You then choose between **Don't delete** and **Move to trash anyway**; until then the profile rests.
- **Confirm change:** If you change the direction of an existing folder profile or switch on **Apply deletions**, LeoSync shows what changes before saving, and you confirm with **Save** or cancel with **Cancel**. With a one-way direction, differing files on the target side are replaced; the replaced version may go to the trash.
- **Removing after backup:** Before LeoSync removes a backed-up photo from the phone, it checks the copy on the PC again. If the PC is not reachable, nothing is deleted ("PC not reachable – nothing deleted"). If the copy is missing or differs, the original stays on the phone and is backed up again on the next run. **Free up space** additionally checks size, partial checksum and modification date.
- **Conflicts:** If a file was changed on phone and PC and no automatic rule is set, you decide which version wins. The other one goes to the trash. On the conflict card the newer side is marked "(newer)"; with the same timestamp (to the second) it says "(same age)". With **Keep both**, the phone file becomes the conflict copy `…_conflict-phone`; if that name already exists, it is called `…_conflict-phone-2`, `-3` and so on. The conflict copy never overwrites an existing PC file. **Undo** after a decision works reliably: once you have undone it, LeoSync no longer carries out the decision, even if a sync is running at that moment. For images and videos the conflict card additionally shows, where it can be determined, the resolution of both sides (with duration for videos); the higher one is labelled "(larger)" but never preselected. Messengers often shrink photos; the file with the higher resolution usually has the better quality.
- **Encryption:** With the **Required** level, LeoSync sends the user name and password only if the connection can be encrypted (see **Turning on encryption**).
- **PC ID:** LeoSync sends the user name and password only to a recognised PC. With an unknown PC, the app does not sign in and skips the profile. The ID is not secret: it protects against an unknown server on a foreign network, not against a targeted attack.
- **Encryption or signing no longer available:** If a profile used to connect encrypted (or signed) and the PC or NAS no longer offers that, LeoSync pauses the profile and transfers nothing. Possible causes: you changed the setting on the NAS or PC, or someone is interfering with the connection on the network. The home screen (in the "Messages" card) and the profile show a card "Encryption not available" (or "Signing no longer available"), the profile card shows the shield icon in red with a warning triangle, the history says "Paused: encryption refused (previously encrypted)", and LeoSync notifies you once. The card has the buttons **Try again** (checks again), **Reduce protection: <profile>** (after a confirmation, sets the profile's encryption to "If possible"; **Cancel** is preselected) and **Open profile**. For signing the button is **Allow without signing**. Only reduce the protection if you changed the setting yourself.
- **Encryption automatically set to "Required":** If the PC actually encrypts while a profile is set to **If possible**, LeoSync switches it to **Required** itself and tells you in the history and with a line at the top of the profile (with **OK**). This protects against a silent downgrade. The level stays freely selectable: if you set it back to **If possible** or **Off**, LeoSync asks ("Less protection?"), and afterwards it never switches this profile automatically again.
- **Different drive detected:** LeoSync remembers the identifier of the drive behind the PC share. If it differs, the folder sync stops before touching any file. The card names the possible causes (hard disk or NAS replaced, drive reformatted, another device at the same address). **Do not sync** leaves the profile paused; **This is the right drive – continue** adopts the new identifier, after which a spot check examines the PC folder. This protects against data loss but is not a protection against a targeted attack. LeoSync uses the creation time of the share as the identifier; if it is recreated on the same drive or a NAS does not deliver it consistently, the card may appear more often. No file is ever lost because of it.
- **Connection cannot be tampered with:** In an encrypted connection LeoSync rejects unencrypted replies and disconnects (the run ends with an error). If a server once signed the connection without encryption, LeoSync requires signing from then on; if it later refuses, the card "Signing no longer available" appears. Connections without encryption and without signing can be altered on the network, which is why encryption is recommended. LeoSync rejects guest and anonymous sign-ins as soon as a user is entered.
- **Renaming and moving (folder profiles):** With **Apply deletions**, LeoSync detects when you rename or move a file or a whole folder and does the same on the other side (instead of deleting and uploading again); the content is checked first. **Without "Apply deletions", both names stay on both sides when you rename, so duplicates arise on purpose.** The history says "renamed/moved: old → new". If your phone's storage location cannot move anything, the detection is off for that profile (nothing is ever copied).
- **Changed and deleted:** With direction **Both ways** and **Apply deletions**: if a file was deleted on one side and changed on the other, it is restored instead of going to the trash; the history says so.
- **Names Windows does not allow:** LeoSync does not upload files with invalid characters, a trailing period or space, or reserved names (e.g. `CON`) to the PC but skips them with a notice (not an error). Names that differ only in upper/lower case are reported as a collision.
- **Storage location without modification time:** If a storage location delivers no modification time for almost all files, LeoSync reports this once per profile and folder.

## 5. Common messages

| Message | What to do |
|---|---|
| User name or password is wrong | Check the Windows user and password. For a Microsoft account, use the e-mail address as the user. Or create a dedicated local user. |
| This share does not exist on the PC | Check the share name or pick it with **Choose folder on the PC…**. |
| No access to this folder | Allow **Change** for the user in the share permissions. If the share requires encryption but the profile is not encrypted, set the profile's encryption to **If possible** or **Required** (the app appends this hint). |
| The PC is not reachable | Is the PC switched on (not asleep)? Is the phone on the same Wi-Fi? Does the firewall allow "File and Printer Sharing"? |
| PC not reachable – nothing deleted | Shown as a message at the bottom (about 8 seconds, dismissible) when LeoSync could not check the PC while removing after backup. The files stay marked and on the phone. Check the connection and try again. |
| The PC is not recognised yet / PC unknown | No sign-in data was sent. At home, open the profile and tap **Test connection**. If the PC provides no ID (e.g. some NAS devices), LeoSync cannot recognise it and does not sign in there. |
| The PC name was not found | Enter the IP address instead of the name, e.g. `\\192.168.1.20`. |
| PC folder not found (safety brake) | Was the folder renamed or moved? Rename it back and tap **Check again** – or choose a new folder. |
| Encryption not available / Encryption refused | The profile requires encryption (or used to be encrypted) and the PC or NAS does not offer it now. Nothing is transferred until you decide. Tap **Try again**. If you changed the setting on the NAS or PC yourself, you can choose **Reduce protection: <profile>**; otherwise leave the profile paused (see section 4). |
| Different drive detected | Behind the share there is a different drive than before (hard disk or NAS replaced, drive reformatted, another device at the same address). The profile is paused and nothing was changed. Choose **Do not sync**, or **This is the right drive – continue** if you caused the change yourself (see section 4). |

## 6. Sync stops in the background

Many manufacturers close apps in the background very aggressively. In LeoSync under **Settings → App permissions**, you can see what LeoSync needs for automatic background sync and what is already done: **notifications** (Android 13 and newer) and **access to photos and videos** (only if you have a photo profile); if one of these is missing, the home screen shows the card “Setup incomplete”. In addition there is **turn off battery optimization**: this is a recommendation, not a must. If it is missing, the home screen shows a neutral tip card; **Not now** hides it permanently, and Settings then shows “Skipped”. LeoSync does not need a location permission.

**Turning off battery optimization:** The button **Open app settings** leads to the App info of LeoSync; there you find the battery setting even on phones with their own battery management. Names differ between manufacturers. How: 1. Tap **Open app settings**. 2. Choose **Battery**, **Battery usage** or **App battery management**. 3. Choose **Unrestricted** (on some phones **Allow background activity** or **Not optimised**). 4. Return to LeoSync. Some phones also need **Auto launch**. The way is confirmed for OnePlus; names may differ for other manufacturers. More: [dontkillmyapp.com](https://dontkillmyapp.com).

**Does a sync run without foreground?** Without the battery exception, Android sometimes does not allow a background sync to show the foreground notification. The **History** then says so ("Ran without foreground: Android can interrupt the sync; it is resumed afterwards …"); it is not an error, and the battery tip card appears once more after "Not now". If Android interrupts the sync, the card says "Paused – Resuming" and LeoSync continues by itself. If the phone rests for a long time (Android power saving), LeoSync resumes at the latest the next time it wakes up; it is more reliable with the battery exception.

## 7. Moving from the old LeoSync app

The LeoSync app from Google Play is a new app (package name `ch.leo.sync`). The earlier version from GitHub (`com.sync2pc.app`) is no longer developed and no longer updates itself; updates now come only through Google Play. You move your profiles with a backup:

1. **Old app:** Pause all profiles so that both apps do not sync the same folders.
2. **Old app:** Export under **Settings → Language & backup → Backup** and save the file. Set an export password, otherwise the backup contains no passwords and you enter them again later. With an export password, the file contains your credentials (encrypted): keep it safe and delete it after the move.
3. **New app:** On the home screen tap **Start moving** and choose **Import backup**. If you do not want to take anything over, tap **Set up fresh** instead: this opens the wizard for a new profile and you create the profiles from scratch. The move card only appears as long as no profile exists.
4. **New app:** Follow the **After the import** card on the home screen: choose folders again where needed, tap **Test connection** once, and start the first sync. The profiles deliberately wait for this first start.
5. **Old app:** Uninstall it only when everything works.

**Important:** Never let both apps sync the same folders at the same time, otherwise two sync states arise. Profiles that used to depend on the Wi-Fi name are switched to the PC ID on import.

## 8. Privacy

LeoSync has no server and collects no data. Passwords are stored encrypted on the phone (Android Keystore). Diagnostic data only leaves the phone if you share it yourself (by e-mail to leotools@protonmail.com, only on your action). LeoSync reads neither your phone's location nor the Wi-Fi name. Only if you choose country folders for a photo profile does LeoSync evaluate the capture location (GPS) in your photos on the phone; it is neither stored nor sent. The details are in the privacy policy.
